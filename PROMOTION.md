### Technical Thread
```
1/ Building DealVault for the @StoryProtocol CDR Hackathon 🔐

A trustless alternative to $500/month virtual data rooms.

Here's how it works 🧵

2/ Problem: Founders pay $99-$25,000/month for data rooms (Datasite, iDeals, Firmex)

All centralized. All require trust.

What if access control was enforced by smart contracts instead?

3/ DealVault uses Story Protocol's Confidential Data Rails (CDR)

• Documents encrypted client-side
• Stored in on-chain vaults
• Access controlled by smart contracts
• No company. No server. Just code.

4/ Two modes:

📁 Deal Room
- Upload confidential docs
- Set authorized wallets
- Define time window (7d, 30d, etc)
- Access revokes automatically on-chain

🔒 Dead Drop
- Sealed documents
- Unlock on future date
- Perfect for wills, succession plans
- Nobody can open it early. Not even you.

5/ The Dead Drop feature is wild.

Upload a document. Set unlock date: Jan 1, 2027.

Nobody can open it. Not you. Not Story. Not anyone.

The smart contract enforces it. That's the power of CDR.

6/ Built with:
• Next.js + React
• @piplabs/cdr-sdk
• Story Testnet (Aeneid)
• Viem + MetaMask

Live demo: [your-vercel-url]

Open source: [github-url]

7/ Why this matters:

$4B VDR market
$211B in VC funding (2025)
Every deal needs a data room

DealVault makes it trustless, on-chain, and cryptographically secure.

Try it: [your-vercel-url]
```
